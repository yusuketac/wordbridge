SETUP

設定

AI接続、文脈、データのバックアップを管理します。
初回セットアップ(無料・約2分)
  1. Google AI Studio を開き、Googleアカウントでログイン
  2. 「Create API key」を押してキーをコピー
  3. 下の欄に貼り付けて「保存」
無料枠(Flash系: 約10回/分・1,500回/日)で十分動きます。クレジットカード登録は不要です。
通常は最速のFlash-Liteを使用します。品質を優先したい場合だけFlashへ切り替えてください。
職種・業界・使用ツール・チーム構成・よく使う専門用語を書き足すと、変換や翻訳の精度が上がります。ここに書いた内容はこのブラウザ内に保存され、AIへの依頼時にだけ送信されます。
業務に必要な情報だけを記載し、機密情報や個人情報は入力しないでください。
学びノート・フレーズ集・設定をJSONファイル1つに保存します。読み込み時は既存データに統合されるため、いま貯まっているものが消えることはありません。OneDrive内に書き出しておけば、別PCから同じファイルを読み込むだけで引っ越し完了です。
注意: 未発表車の情報など機密情報は入力しないでください（社内ルール）。設定はこのPCのブラウザ内にのみ保存されます。

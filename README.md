# WordBridge

敬語変換・文書作成・翻訳・学習を一つにまとめた、単一HTMLのビジネスコミュニケーションアプリです。

- **敬語変換**: 相手と用件を選び、普段の言葉を自然な敬語へすぐ変換
- **文書作成**: 箇条書きの要点から、メールやチャットの下書きを作成
- **翻訳**: 日英を自動判定して即翻訳(訳語の選択理由メモ付き)
- **文書校正**: 宛先トーン別(カジュアル / 上司・社内 / 社外)の添削+理由の解説、PREP法の構造分析
- **コーチ**: 校正から実際に見られた改善傾向を記録し、繰り返す項目を「要チェック」として振り返り。接続詞・敬語・報告なども質問可能
- **フレーズ集**: 定型文の登録・ワンクリックコピー(使用回数ソート)
- **マナーガイド**: 依頼・報告・メール・チャットなどの場面別原則と例文を検索
- **学びノート**: 添削から得た学びを自動蓄積し、よく指摘されるポイントを可視化
- **バックアップ/復元**: 全データをJSONで書き出し・統合読み込み

## 実例で振り返る

- **学びノート**: 整える・添削・文書作成の原文、改善後、指摘箇所、理由、次に試すことを自動保存します。検索は原文・理由にも対応し、CSVと全コピーにも実例が含まれます。原文・結果に存在しない引用は採用しません。
- **その場のコーチ**: 校正結果に具体例と次の一歩を表示。文書作成は「要点をどう文章にしたか」を説明し、箇条書きをミスとは扱いません。同僚・チャットは短い、やわらかいですます調です。
- **履歴から見える傾向**: コーチ画面で直近30日／保存されている全期間を分析します。端末内で処理し、過去の本文は再送しません。同じ原文は1件として集計し、根拠の実例を表示します。これは保存された指摘の集計であり、旧履歴の包括的なAI再分析ではありません。
- **マナーガイド**: 40件の原則・例文を状況と相手で絞り込み、例文をコピーできます。よく使う例文は☆からお気に入りへ登録し、「お気に入りだけ」で再表示できます。【】を実際の内容に置き換えてから使ってください。

旧ノートに原文や理由がない場合は補完しません。旧履歴では、前後の文章から確認できる一部の敬語表現だけを確認候補として表示します。履歴を消しても学びノートの実例は残るため、本文を消したい場合は両方を確認してください。

学びノートは最大2000件、履歴は最大150件。保存容量不足の場合は警告を出し、AIの結果は画面に残します。バックアップver.6は実例とマナーのお気に入りも保持し、旧形式も読み込めます。バックアップやCSVには原文が含まれるので保管先に注意してください。

## 検証

開発用テストは node tests/learning.test.cjs。外部通信をしない模擬DOM・ダミーデータで、保存、旧形式互換、伏せ字、主要ボタンからの学習導線を確認します。ブラウザのレイアウト検証や実際のGemini応答品質の評価とは別です。

## 使い方

[公開ページ](https://yusuketac.github.io/wordbridge/) を開くか、`index.html` をダウンロードしてブラウザで開くだけで動きます。ビルド・インストール不要。

設定タブの「ペルソナ」欄に職種・業界・使用ツール・チーム構成などを書いておくと、変換や翻訳がその文脈に合わせて調整されます。初期値は一般的な文面です。

AIには Google Gemini API(無料枠)を使用します。APIキーは設定タブから各自で登録してください。APIキー、設定、フレーズ、学びノートはブラウザの localStorage に保存されます。敬語変換・文書作成・翻訳・校正へ入力した文章は、処理のためGoogle Gemini APIへ送信されるため、機密情報は入力しないでください。

敬語変換・文書作成・翻訳・校正では、必要に応じて「誰へ・何について・どの場面で送る文章か」を前提条件へ入力できます。4機能とコーチは`Enter`で実行、`Shift+Enter`で改行します。コーチ記録はブラウザ内に保存され、バックアップにも含まれます。

複数の端末で使う場合、学びノートやフレーズ集は端末ごとに別々に貯まります(データがブラウザ内に保存されるため)。設定タブのバックアップ書き出し/読み込みで合体できます。読み込みは統合方式なので、既にあるデータが消えることはありません。

速度優先の既定モデルは`gemini-3.5-flash-lite`で、Gemini 3系では思考量を`MINIMAL`へ固定します。短い文章用の出力上限、文章系プロフィールの圧縮、同一画面内の再変換キャッシュを使い、完了時に実測秒数を表示します。408・429・5xxの一時エラーは、長時間待たせないよう短い待ち時間で1回だけ再試行します。

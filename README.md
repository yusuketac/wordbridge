# コトバデスク

翻訳 & ビジネス文書コーチ。単一HTMLファイルで動く個人用ツールです。

- **翻訳**: 日英を自動判定して即翻訳(業界用語を考慮した訳語メモ付き)
- **文書校正**: 宛先トーン別(カジュアル / 上司・社内 / 社外)の添削+理由の解説、PREP法の構造分析
- **フレーズ集**: 定型文の登録・ワンクリックコピー(使用回数ソート)
- **学びノート**: 添削から得た学びを自動蓄積し、よく指摘されるポイントを可視化
- **バックアップ/復元**: 全データをJSONで書き出し・統合読み込み

## 使い方

[公開ページ](https://yusuketac.github.io/kotoba-desk/) を開くか、`index.html` をダウンロードしてブラウザで開くだけで動きます。ビルド・インストール不要。

AIには Google Gemini API(無料枠)を使用します。APIキーは設定タブから各自で登録してください。キーや入力データが外部に保存されることはなく、すべて使用中のブラウザの localStorage にのみ保存されます。
